# BuildOffice Copilot

Program-wide local intelligence layer for BuildOffice Pro.

It indexes the actual application source tree, navigation catalog, UI symbols, Python classes/functions, SQLite tables/columns/foreign keys, settings and translation keys. It also queries live project/management data through existing application services.

Capabilities include program explanation, page/function/database discovery, architecture and data-flow questions, project analysis, comparisons, management intelligence, and parameterized natural-language queries.
